BSA Bulletin folder structure

bulletin/
├── index.html
├── bulletin.json
└── images/
    ├── welcome-gathering.jpg
    ├── fall-graduates.jpg
    └── community-update.jpg

To add a Bulletin item:
1. Put the image inside the images folder.
2. Add one new object to bulletin.json.
3. Use a date in YYYY-MM-DD format.
4. Set image to images/your-image-file.jpg.
5. Facebook and Instagram can be left as empty strings if there is no link.

The webpage automatically sorts entries newest first.
